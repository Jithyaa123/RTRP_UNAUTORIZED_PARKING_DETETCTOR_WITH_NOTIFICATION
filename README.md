🚗 IoT Based Unauthorized Parking Detector with Notification System
The IoT Based Unauthorized Parking Detector with Notification System is a smart parking management solution designed to monitor parking areas, prevent unauthorized vehicle access, and improve overall parking efficiency. This system uses an ESP32 microcontroller integrated with an EM18 RFID reader to identify vehicles through RFID tags. When a vehicle arrives, the RFID reader scans the tag and sends the data to the ESP32, which verifies whether the vehicle is authorized. If the vehicle is authorized, the system automatically opens the gate using a servo motor, displays a confirmation message on the LCD, and logs the entry data to the ThingSpeak cloud platform. If the vehicle is unauthorized, the gate remains closed, a buzzer alert is triggered, and a real-time notification is sent to the user through the Blynk IoT platform.
The project aims to provide a secure, automated, and efficient parking system by reducing manual intervention and human errors. It ensures that only authorized vehicles can access parking spaces while providing real-time updates and alerts. The system also stores parking data in the cloud, allowing users to monitor and analyze parking activity remotely. Key components of the system include ESP32, RFID reader, servo motor, LCD display, buzzer, and IoT platforms such as Blynk and ThingSpeak. The software is developed using Arduino IDE and Embedded C/C++, enabling smooth integration between hardware and cloud services.
